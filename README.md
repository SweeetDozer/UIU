# p

Начальный каркас Python-проекта. Внешних зависимостей пока нет.

## Подготовка

```bash
python3 -m venv .venv
source .venv/bin/activate
```

## Запуск

```bash
python main.py
```

Пока приложение ничего не выводит. Основной код добавляй в функцию `main()`
в файле `main.py`.

## Файлы

- `main.py` — точка входа в приложение.
- `.gitignore` — исключения для Git.
- `.editorconfig` — общие настройки отступов и форматирования.
